# Shineos Tech Blog

**Shineos Tech Blog** は、**株式会社シャイオス（Shineos Inc.）** が運営する公式テックブログです。

AI・クラウド・Web開発・プロダクト設計を中心に、
**SaaS開発支援やオフショア開発の現場で培った実践知**をもとに、
**「実務で本当に使える技術と考え方」** を発信しています。

🌐 **Site**: [https://blog.shineos.com/](https://blog.shineos.com/)

---

## このブログについて

本ブログでは、以下のようなテーマを扱います。

* 🤖 **AI / エージェント / 自動化**
* ☁️ **クラウド（AWS / GCP / Azure）**
* 🧑‍💻 **Web開発（TypeScript / React / Svelte / Astro）**
* 🏗 **SaaS設計・アーキテクチャ**
* 🌍 **オフショア開発・分散開発の実践**
* 🚀 **スタートアップ・プロダクト開発の知見**
* 🔐 **セキュリティ・運用・ガバナンス**

単なる技術紹介にとどまらず、
**「なぜその選択をしたのか」「現場でどう使われているのか」** を重視しています。

## 記事の方針

* 実務での利用を前提とした内容
* 法人・開発チームで再利用できる知見
* SaaS・オフショア開発の現場視点を重視
* 長期的に価値が残る記事を優先
* 過度な煽りや広告目的の記事は掲載しません
